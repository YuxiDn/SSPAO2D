## 2026-06-01 随机像差一致性训练逻辑更新

事件：在 `scripts/train_self_supervised.py` 中加入随机像差一致性训练分支，并同步更新 `configs/self_supervised_2d.json` 与 `configs/self_supervised_2d_adv1_nocoeffl2.json`。该逻辑已提交到 GitHub，commit 为 `0190267 Add random re-aberration consistency loss`。

### 核心思想

当前 ABE 系列网络输出为：

```text
F(y) = (x_hat, a_hat)
```

其中 `x_hat` 是网络恢复出的 object / clean image，`a_hat` 是预测的 Zernike 像差系数。随机像差一致性要求：如果 `x_hat` 真的是物体本身，那么对它重新施加任意随机像差后，再送回网络，object 输出应该回到同一个 `x_hat`，而 zernike 输出应该变成新施加的随机系数。

训练流程：

```text
y: 真实含像差输入

(x_hat, a_hat) = F(y)
x_ref = detach(x_hat)

a_r = random_zernike()
y_r = D_{a_r}(x_ref)

(x_r, a_r_pred) = F(y_r)
```

新增约束：

```text
L_random_obj = |x_r - x_ref|
L_random_coeff = |a_r_pred - a_r|
```

这里 `x_ref = detach(x_hat)` 很重要：第一遍输出作为 pseudo-clean target，不让该 loss 同时拉动两边一起塌缩，降低平滑平凡解风险。

### 与原有 clean object synthetic cycle 的关系

该逻辑不是替代原来的 clean object synthetic 分支，而是与它配合：

```text
x_clean -> D_{a_r}(x_clean) -> F(D_{a_r}(x_clean)) ≈ (x_clean, a_r)
```

clean object synthetic 分支提供“什么是 clean object / 什么是正确 Zernike”的强锚点；随机像差一致性分支则检验真实含像差图像的网络输出是否已经像一个可再次成像的物体。

因此当前推荐训练目标为：

```text
L_total =
  L_real_reprojection
+ L_synthetic_object
+ L_synthetic_zernike
+ L_identity
+ L_phase
+ L_random_reaberration
+ L_tv
+ L_coeff_l2
+ L_adv(optional)
```

## 2026-06-02：Pupil phase -> pairwise difference -> Zernike projection 分支

### 背景

希望让像差分支更像一个 OTF 逆过程，而不是简单的全连接 Zernike coefficient head：

```text
已知像差图像的频域分布
  -> 复杂逆函数
  -> pupil phase phi_hat
  -> pairwise phase / OPD difference
  -> Zernike difference projection
  -> a_k
```

核心动机：

- 不直接让网络从 feature 回归 `a_k`。
- 先让网络利用退化图像频域幅值、相位证据，恢复一个中间的 pupil phase 表示。
- 再通过固定的 pairwise difference 几何和 Zernike difference 最小二乘投影得到 `a_k`。
- 中间变量 `phi_hat`、`Delta_phi_hat` 更容易解释和可视化。

### 本次代码更新

新增模块：

```text
src/ao2d/models/zernike_projection.py
```

包含三个主要类：

```text
ZernikeDifferenceProjection
DeltaPhiZernikeProjectionHead2D
PupilPhaseZernikeProjectionHead2D
```

其中 `PupilPhaseZernikeProjectionHead2D` 是当前更符合目标的结构：

```text
aberration fused feature: [B, C, H, W]
  -> Conv + residual blocks
  -> global pooling + MLP
  -> phi_hat: [B, P, P]
  -> fixed pairwise difference layer
  -> Delta_phi_hat: [B, M]
  -> fixed least-squares Zernike difference projection
  -> a_k: [B, K]
```

这里：

```text
P = delta_phi_pupil_grid_size
M = delta_phi_pair_count
K = zernike_modes
```

固定投影关系：

```text
Delta_phi_hat ≈ D a
D[j, k] = Z_k(p1_j) - Z_k(p2_j)
a = (D^T D + lambda I)^(-1) D^T Delta_phi_hat
```

### 频域幅相输入

新增 `LogFFTAmplitudePhase2D`，用于把退化图像 FFT 后的幅值和相位同时输入 aberration branch：

```text
Y = FFT(y)
frequency input = [log|Y|, cos(angle Y), sin(angle Y)]
```

使用 `cos(angle Y)` 和 `sin(angle Y)` 是为了避免直接使用 wrapped phase 带来的 `pi` / `-pi` 不连续问题。

### 已接入模型

以下模型现在可以通过配置选择新 head：

```text
ABEFusionNet2D
ABEFusionNetV2D
ABESplitNet2D
```

factory 已支持透传配置项：

```json
{
  "aberration_head_type": "pupil_phase_projection",
  "fft_phase_features": true,
  "delta_phi_pair_count": 512,
  "delta_phi_pupil_grid_size": 32,
  "delta_phi_ridge": 0.0001,
  "delta_phi_max_opd": 0.75
}
```

也保留了较短路径：

```json
{
  "aberration_head_type": "delta_phi_projection"
}
```

该路径为：

```text
feature -> Delta_phi_hat [B, M] -> fixed Zernike difference projection -> a_k
```

### 与原始 coefficient head 的区别

原始路径：

```text
aberration fused feature -> ResNet / MLP -> a_k
```

新路径：

```text
FFT amplitude/phase evidence + spatial/gradient features
  -> phi_hat on pupil grid
  -> pairwise difference
  -> Zernike difference projection
  -> a_k
```

新路径更像：

```text
OTF / frequency evidence 的逆问题近似
```

而不是纯粹黑箱回归。

```python
amp = torch.log(1 + torch.abs(spectrum).clamp_min(1e-8))
```


### 观察重点

优先与 `abenetv2d_fftphase_adv05_gpus23` 对比：

```text

loss_phase / loss_phase_grad
loss_zernike_coeff_l1
loss_random_reaberration_coeff
loss_random_reaberration_object
```

判断逻辑：

- 如果 `zernike_mae` 更低但 `object_psnr/object_ssim` 继续下降，说明 pupil phase projection 主要强化了 aberration 表示，但 object branch 仍受 cycle / GAN 目标牵引。
- 如果 `loss_phase` 和 `zernike_mae` 同时下降，说明 `phi_hat -> projection` 分支可能比直接 coefficient head 更适合当前物理约束。
- 如果早期 `zernike_mae` 仍在 2k-5k iteration 后恶化，下一步应考虑 coefficient / phase loss warmup-decay，或显式加入 `L_proj/L_smooth` 并监控中间 `phi_hat`。
